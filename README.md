# Teemu’s Snake

Install Visual Studio 2026 with the **Desktop development with C++** workload, including the MSVC x64/x86 tools and a Windows SDK.

Extract the whole archive. In Visual Studio, open `Claudius.slnx`, select **Debug | x64**, and press **F5** to build and run. Use the arrow keys to steer and close the game with the window’s close button.

The project uses the Visual Studio 2026 v145 toolset and the **Latest** C++ language mode. The build copies the bundled SDL2 runtime next to the executable. Find the x64 debug build under `Build/x64/Debug`.
